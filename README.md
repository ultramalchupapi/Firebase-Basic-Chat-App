# Firebase Basic Chat App

A chat application built with React, Firebase Authentication, and Cloud Firestore. It supports email/password and Google sign-in, room-based messaging, and real-time message updates.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
